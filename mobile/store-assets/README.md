# Aset Google Play Store

Folder ini berisi aset listing Fase 27.

- `play-store-icon-512.png` — ikon listing Play Store, 512 × 512, dengan
  interpretasi mandala modern Dewata Nawa Sanga.
- `dewata-nawa-sanga-source.png` — artwork sumber resolusi tinggi untuk ikon
  listing dan splash screen Android.
- `feature-graphic-1024x500.png` — feature graphic, 1024 × 500.
- `raw-home.png`, `raw-calendar.png`, `raw-saved.png`, dan `raw-about.png` —
  screenshot asli dari build debug yang berjalan pada emulator Android.
- `playstore-01-hari-ini.png` sampai `playstore-04-transparan.png` — screenshot
  Play Store siap unggah, dengan frame perangkat dan copy promosi.

Sebelum publikasi, ambil ulang screenshot dari build release agar semua teks,
data kalender, dan status koneksi mencerminkan aplikasi final. Jangan gunakan
data akun atau informasi pribadi pada screenshot publik.

# MASTER PROMPT PENGEMBANGAN APLIKASI WARIGA BALI SANTIH

Saya ingin membangun aplikasi bernama:

# Wariga Bali Santih

Wariga Bali Santih adalah aplikasi Kalender Bali dan pencarian dewasa ayu yang membantu pengguna:

* melihat informasi Kalender Bali;
* mengetahui Wewaran, Wuku, Sasih, Penanggal, dan Pangelong;
* memilih jenis kegiatan;
* mencari rekomendasi tanggal;
* melihat alasan rekomendasi;
* melihat pantangan atau hal yang perlu dipertimbangkan;
* menyimpan hasil;
* membagikan hasil;
* melihat detail perhitungan melalui Mode Ahli.

Aplikasi harus terasa seperti **konsultan Wariga digital**, bukan hanya kalender biasa.

Pengguna tidak harus memahami seluruh istilah Wariga. Sistem harus memandu pengguna dengan alur:

```text
Pilih kegiatan
→ Pilih rentang tanggal
→ Sistem memeriksa setiap tanggal
→ Sistem memberi beberapa rekomendasi
→ Pengguna membuka detail
→ Sistem menjelaskan alasan dan pertimbangan
→ Pengguna dapat menyimpan atau membagikan hasil
```

## Service

Buat:

```text

```

Method:

```php
search(
    int $activityId,
    Carbon $startDate,
    Carbon $endDate,
    array $options = []
): DewasaSearchResult;
```

## Proses

Untuk setiap tanggal:

1. Hitung Calendar Engine.
2. Ambil data lunar jika tersedia.
3. Bentuk objek atribut tanggal.
4. Ambil rule verified untuk kegiatan.
5. Evaluasi rule.
6. Hitung skor.
7. Tentukan status.
8. Simpan alasan utama.
9. Masukkan ke ranking.

## Ranking

Urutkan berdasarkan:

1. status;
2. skor tertinggi;
3. jumlah rule positif;
4. pantangan paling sedikit;
5. tanggal terdekat.

## Batasan

* Rentang publik maksimal 366 hari.
* Gunakan chunk processing.
* Gunakan cache.
* Cache dibedakan berdasarkan:

  * kegiatan;
  * tanggal awal;
  * tanggal akhir;
  * engine version;
  * rule version;
  * mode.
* Cache dibersihkan jika rule verified berubah.

## Output

```json
{
  "summary": {
    "total_dates_checked": 30,
    "recommended_count": 8,
    "consideration_count": 12,
    "avoid_count": 10

}
```
